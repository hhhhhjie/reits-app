# 知行行情 Android v1.2.0

约23 MB，Android 7.0及以上ARM64手机。同一开发签名、versionCode 3，可覆盖上一版以保留本机自选和参数。手机系统浏览器下载后允许安装未知应用，打开APK安装。若聊天软件内置浏览器拦截下载，请复制链接到系统浏览器打开。

新增“数据 → 可转债 / REITs → 设置筛选”：指标上下限、多条件组合、符合数量预览、单项清除；每类可保存10套命名方案，并分别恢复上次应用的条件。可转债支持价格、溢价、双低、到期收益率估算、评级、赎回公告等；REITs支持净值溢价、历史现金分派率等。负数、万元/亿元换算与缺失数据均有明确处理。

沿用沪深可转债和公募REITs完整名单、全局搜索/排序/分页。2026-10-19数据核验308只转债、88只REITs，均有真实报价；88只REITs均有披露净值和近12月现金分红统计。名单动态更新，不固定数量。

缺失数据显示“—”，演示和缓存有明确标记。净值不是IOPV，历史分派率不是未来收益；发行规模不是剩余规模，尚无强赎15/30日计数。

41项接口/计算/筛选测试、24项手机/桌面交互测试通过，APK签名、版本、CRC、内置Hermes资源与16KB打包对齐校验通过。尚未真机安装验证。

查看 SHA256SUMS 核对下载文件；ZIP内含同一个APK、安装说明和验证记录。保留v1.1.0固定文件名供核对，当前试用请下载v1.2.0。
